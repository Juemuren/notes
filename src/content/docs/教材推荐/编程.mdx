本课程学习编程中最基础的概念，包括变量、赋值、表达式、语句、循环、条件、函数等。这些是无关具体语言的编程技术，请不要纠结于语法细节和各种标准库函数如何使用——这些直接查询文档即可。

《CS50x》是 Harvard 大学的计算机导论课，其语言组合覆盖了常见的编程需求，很适合作为编程基础课。

1. 课程从 C 语言开始学习，这是相对低级的语言，适合理解计算机底层设计。计算机系统、操作系统、系统编程、网络编程等课程都要求掌握 C 语言。
2. 课程随后过渡到 Python，这是相对高级的语言，适合理解计算思维和算法逻辑。人工智能、数值分析等课程都要求掌握 Python。
3. 课程最后接触了一点 SQL 和 Web，这完全满足现代软件开发的需要，适合理解实际的应用开发场景。

如果不喜欢跟着课程学习，也可以自己阅读教材。

- 如果你有一定的程序设计基础，或者天赋异禀，可以直接看《C 程序设计语言》。这是 C 语言的设计者写的书，绝对的权威教材。
- 如果你毫无编程经验，那么可以试试《C Prime Plus》。这相比另一本书厚很多，对初学者更加友好。

至于 Python、SQL、Web，从参考手册中了解一下基本语法和主要标准库就足够了。

### 面向对象编程

**弱依赖：** [编程基础](#编程基础)

面向对象编程是一种非常重要的编程范式。本课程将学习面向对象编程中最基础的概念，包括封装、继承、多态等。这些同样是无关具体语言的编程技术。

课程选择使用 C++ 学习面向对象编程，有以下几个主要原因。

1. C++ 中有关面向对象编程的基本概念足够齐全。
2. 后续的设计模式、软件工程、计算机图形学、游戏开发等课程都要求掌握 C++。
3. C++ 基本语法和 C 语言相同。因此，如果已经有了 C 语言的基础，那么可以把精力更多地放在面向对象编程上，而不是被语法细节搞得晕头转向。

关于选用的教科书《C++ Primer》，我个人觉得比较一般。

- 本书大部分篇幅都在纠结 C++ 的语法和标准库的接口，而讲面向对象编程和泛型编程则分别只有一章。
- 本书讲了标准库的接口，却很少讲为什么要这样设计标准库。
- 本书讲了面向对象编程的语法，却很少讲面向对象编程应该学习的实践原则。

但鉴于这本书网上口碑不错，因此仍然选择这本书作为教材。不过阅读的时候记得取舍，不要被 C++ 的语法细节淹没。

- 本书的第一部分讲语法，如果你有 C 语言基础，那么基本可以略过。
- 本书的第二部分讲标准库，不用花太多时间，用来参考即可。
- 本书的第三部分讲类设计工具，重点关注其中的面向对象编程和泛型编程部分。

### 函数式编程

**弱依赖：** [编程基础](#编程基础)、[离散数学](数学.mdx#离散数学)

<ResourceGrid>
  <BookCard
    title="计算机程序的构造和解释"
    url="https://book.douban.com/subject/1148282/"
  />
  <WebCard title="Scheme 参考手册" url="https://man.scheme.org/" />
</ResourceGrid>

尽管本课程名为“函数式编程”，但所选教材的内容并不局限于函数式编程。

《计算机程序的构造和解释》一书的定位存在很大争议。这是 MIT 计算机科学的入门教材，正如书名所说，其介绍了程序如何构造以及如何解释。但我更愿意称该书为一本编程哲学书，因为所讨论的内容常常涉及到计算机程序的本质。这不是一本讲述特定编程语言语法的书。相反，这是一本有助于培养抽象思维和理解计算本质的书。

全书采用 Lisp 进行教学。该编程语言不太主流，但其特性很适合课程需要。

1. Lisp 支持函数式编程。函数式编程是一种很独特的编程范式。在函数式编程中，只有函数，没有别的变量。所有的过程和数据都是通过函数实现的。
2. Lisp 不仅仅支持函数式编程。通过支持赋值，代码中产生了非函数的变量。有了变量后，就可以构造更高级的对象，实现更高级的操作。
3. Lisp 的有很强的元语言抽象能力。元语言是用来定义其它语言的语言。而元语言抽象是指语言把自身作为元语言去创造新语言。Lisp 的元语言抽象能力非常强，因此可以很简单地去设计一门新的语言（通常称为 Lisp 方言）。

全书共 5 章，大概可分为 3 个部分。

1. 第 1 章和第 2 章围绕着函数式编程展开，通过简单的函数来实现过程和数据，随后使用过程和数据来构建更复杂的程序。
2. 第 3 章则突破了函数式编程的框架，通过引进赋值，程序拥有了状态，从而可以利用状态来编写程序。
3. 第 4 章和第 5 章开始讨论语言自身，通过元语言抽象来用语言去创造语言，通过寄存器机器模型来理解实际机器如何执行程序。

该书的习题很有价值，可以挑选部分尝试完成。

### 开发工具

**弱依赖：** [编程基础](#编程基础)

<ResourceGrid>
  <WebCard
    title="计算机教育中缺失的一课"
    url="https://missing-semester-cn.github.io/"

</ResourceGrid>

本课程学习如何使用常见的开发工具，包含命令行、编辑器、数据整理、版本控制、程序调试、性能分析、编译构建、密钥生成等。

《计算机教育中缺失的一课》以 Linux 作为主要教学平台，macOS 可以无痛兼容。如果你使用的是 Windows 系统，那么讲义第 1 节的练习会教你怎么安装 WSL——这是 Windows 上的 Linux 子系统，足够满足本课程的需要。

讲义里附有简单的练习，可以尝试去完成。不过，完成这些练习并不代表真正掌握了所有开发工具。

我在学完本课程后，还花费了至少上百小时来学习如何使用开发工具——这是一个无底洞，每个工具都可以深究，工具与工具间的组合也可以探索。并且，工具自身也会不断演化改进，时不时还会有全新的工具冒出来。

因此本课程的目的不是让你完全掌握这些开发工具，而是让你知道有哪些开发工具，了解这些工具分别有什么用，以及学会大致的用法。本课程所学的知识大概率无法直接帮你解决实际开发中遇到的难题。但是，本课程会让你知道遇到这种难题时应该使用哪些工具。你可以因此更深入地去研究该工具从而解决实际问题。

本课程推荐两套教材，可以自行选择。

1. 《数据结构与算法分析》中的示例使用 C 语言。因此选用《数据结构与算法分析》作为教材，最好有 C 语言基础。
2. 《算法导论》中的示例使用伪代码。因此选用《算法导论》作为教材，不要求有 C 语言基础，但最好还是有点编程基础，至少要能看懂伪代码。

另外，与《数据结构与算法分析》相比，《算法导论》多了许多内容，这些主要集中在该书的第七部分。这部分内容涉及到线性代数、信号与系统、凸优化等数学课程，建议初学者跳过这部分。如果确实对这些内容感兴趣，那么可以学习对应的数学课程，或者学习数值分析——这门课专门讨论复杂数学问题的算法。去掉这部分后，《算法导论》的篇幅就和《数据结构与算法分析》差不多了。

### 设计模式

**强依赖：** [编程基础](#编程基础)、[面向对象编程](#面向对象编程)

<ResourceGrid>
  <BookCard title="设计模式" url="https://book.douban.com/subject/34262305/" />
</ResourceGrid>

本课程学习如何使用面向对象技术设计复杂的软件系统。

《设计模式》使用 C++ 和 Smalltalk 这两种支持面向对象编程的语言进行教学。

Smalltalk 是面向对象编程语言的鼻祖，只支持面向对象编程，并且从语言设计到编程实践都完整地贯彻了面向对象编程的理念。不过我认为没必要专门为了本课程学习 Smalltalk，实在看不懂的话，这部分代码示例跳过就行了。

本书采用总分的结构，并以理论和实际相结合的方法教学。

1. 本书开头讲解为什么要学习设计模式，并介绍了相关理论，然后以一个具体的例子展示如何综合运用各种设计模式来解决复杂的软件设计问题。
2. 本书接着将设计模式按功能分类，并依次详细地介绍每个设计模式。对于每个设计模式，都是理论和实际结合着介绍。

书中有非常多的设计示例。包括图形界面的设计、编译器的设计、操作系统的设计、文本编辑器的设计、迷宫游戏的设计等。部分示例可能需要一点相关知识才能完全理解，比如对于编译器示例，如果不懂编译原理，就不清楚每个类为什么要这样设计。

但本书的重点是学习设计模式，而不是理解每个示例。如果某个未能完全理解的示例并没有影响到对该设计模式的掌握，那么跳过就行了。

本课程学习 Web 技术。

现代 Web 技术已经不局限于制作网站

- 几乎所有的用户界面，包括桌面应用、移动应用等都可以基于 Web 实现
- 甚至服务端的应用也可以跑在 NodeJS 这个脱胎于 Web 技术的语言。

《全栈公开课》是 Helsinki 大学的公开课程，它覆盖了 Web 开发的所有主要内容。

前 7 部分使用以下技术构建了一个全栈应用。

- 使用 React 构建前端。
- 使用 NodeJS 和 Express 构建后端。
- 使用 MongoDB 作为数据库。
- 使用 Vitest 和 PlayWright 作为测试框架。
- 介绍 React Router、MUI、Styled 等库。
- 介绍 Zustand 状态管理方案。
- 介绍 Vite 和 esbuild 打包工具。

而第 7 部分之后，课程介绍了一些新兴技术。

- 讲解如何用 TypeScript 实现类型安全。
- 讲解如何用 GraphQL 设计服务端点。
- 讲解如何用 React Native 构建移动应用。
- 讲解如何用 Next.JS 完成全栈开发。
- 以 PostgreSQL 为例介绍关系型数据库。
- 以 Docker 为例介绍容器技术。
- 以 GitHub Actions 为例介绍持续集成技术。
