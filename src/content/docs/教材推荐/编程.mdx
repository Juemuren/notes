### 编程基础

<ResourceGrid>
  <WebCard title="CS50x" url="https://cs50.harvard.edu/x/" />
  <WebCard title="C 参考手册" url="https://en.cppreference.com/c/" />

本课程以哈佛大学的 CS50x 作为基础，从 C 开始学习，然后过渡到 Python，最后接触了一点 SQL 和 Web。

学习本课程是为了解编程的基本概念，不要纠结于语法细节和各种标准库函数如何使用——这些直接查询文档即可。
