## 如何学习新技术

技术领域日新月异，今天的教程到了明天就可能因为一次更新而过时。因此，官方文档始终是最重要的学习资料，任何二手文档都只能用作参考。由于英文文档通常比中文文档更新得更及时，所以应该优先阅读英文文档。当然，如果 LLM 有联网搜索功能，那么用其快速总结文档内容也不失为一种选择。

## 如何学习新知识

知识相比技术更加理论，并且短期内变化不会太大，因此可以参考那些经受了时间考验的优秀教材，直接询问 LLM 通常也能得到不错的回复。

对于教材形式的选择，我的偏好是 `网页 > 书籍 > 视频`。

- 视频中存在很多冗余的视听元素影响主要内容的获取，并且视频难以保存，不方便重温
- 书籍可以方便地离线保存和标记书签，并且目录结构通常很清晰，方便重复学习
- 网页可以借助浏览器方便地翻译内容，可以插入动态的、可交互的元素用于理解和探索，可以不断地更新以补充内容或修正错误

不过由于优秀的网页教材比较少，因此我使用的教材还是以书籍为主。
