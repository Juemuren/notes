## 简介

https://mdxjs.com/

MDX 可以在 Markdown 文档中编写 JSX，之后打包工具会将其编译为 JavaScript，从而消除运行时开销

## 对比

相比 Markdown，MDX 增加了 JSX 语法支持，使得可以在文档中嵌入 JSX 组件，甚至直接编写 JavaScript 代码。这样文档不仅可以利用 JSX 组件来改善页面样式，还可以利用 JavaScript 代码在文档中增加动态内容

## 安装

MDX 的生态相当不错，可以和许多打包器、静态网站生成器、前端框架、编辑器等集成。具体方式可以参考 [Getting started](https://mdxjs.com/docs/getting-started)。
